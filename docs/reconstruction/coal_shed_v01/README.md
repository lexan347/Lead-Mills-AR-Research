# Lead Mills Coal Shed Blockout v01

Provisional blank 3D massing model for the small roadside building labeled **COAL SHED** on the supplied 1890 Forest River Lead Mills property plan.

## Dimensions
- Length: 24.0 ft (7.3152 m)
- Width: 12.0 ft (3.6576 m)
- Eave height: 8.5 ft (2.5908 m)
- Ridge height: 11.5 ft (3.5052 m)
- Roof pitch: 6:12
- Coordinate convention: X = length, Y = vertical, Z = width
- Origin: center of footprint at grade
- Model units: meters

## Confidence
These are **provisional reconstruction dimensions**, not surveyed dimensions. The supplied property plan gives a footprint and relative proportions but no explicit shed dimensions. Absolute size and height are therefore estimated from the plan geometry and period New England shed precedents.

## Scope
Blank shell only. No openings, cladding, frame members, foundation, color, or textures yet.
